# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.7] - 2023-12-xx
### Changed
- Support IntelliJ 2023.3 and later (#1.7)
- Updated `since-build` compatibility to 193+

## [1.6] - 2023-xx-xx
### Changed
- Usage of `JBUIScale` instead of deprecated `JBUI` scale calls

## [1.5] - 2022-xx-xx
### Fixed
- Fix project language level

## [1.4] - 2021-xx-xx
### Changed
- Usage of new JetBrains API

## [1.3] - 2020-xx-xx
### Fixed
- Fix icon rendering issues

## [1.2] - 2020-xx-xx
### Fixed
- Fix images in plugin description

## [1.1] - 2020-xx-xx
### Added
- Bigger icons (`@2x`) for HiDPI / larger screens
- Double-sized trainer and Pikachu assets

## [1.0] - 2020-05-xx
### Added
- Initial release of Pokemon Trainer Progress Bar
- Determinate bar: Red and Pikachu
- Indeterminate bar: Bike animation
- Based on Nyan Progress Bar by Dmitry Batkovitch
- JetBrains Marketplace publication
